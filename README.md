# Social Monitor

A Chrome extension that monitors Reddit posts and other similar platforms. see posts from your favorite subreddits and users with customizable notifications.

## Features

- Monitor multiple subreddits
- Follow specific Reddit users
- Filter posts by keywords (include/exclude)
- Sort by new, hot, top, or rising
- Time-based filtering (last 5 mins, 10 mins, 30 mins, 1 hour, 24 hours)
- Desktop notifications
- Customizable check intervals (10 mins to 1 hour)
- Minimal, clean UI
- No account required
- Free and open source

## Installation

### Chrome

1. Download or clone this repository
2. Go to `chrome://extensions/`
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the extension folder

## Usage

1. Click the extension icon in your browser
2. Click "Fetch Posts" to see latest posts
3. Click "Settings" to customize:
   - Subreddits to monitor
   - Users to follow
   - Keywords to filter
   - Notification preferences
   - Check intervals

## Permissions

This extension requires:
- **storage**: To save your settings
- **alarms**: To schedule checks
- **notifications**: To send desktop notifications
- **host_permissions**: To access Reddit's API

## Privacy

- No data is collected or sent to any server
- All settings are stored locally in your browser
- No tracking or analytics
- Open source - review the code yourself
